## How to read and refresh

- Read visual values (colours, sizes, spacing, copy) straight from these files: inline `style`
  attributes hold them, and the `<script type="text/x-dc">` block at the end of each file holds
  the sample data and the colour maps.
- `support.js` only renders the mock inside the canvas and is not copied.
- To refresh: read the canvas's `project/*.dc.html` and `project/canvas.json` again and
  overwrite these files whole; never hand-patch them. Regenerate the table above from the files.
